Purpose

Build a personal leadership toolkit and portfolio you can keep and use beyond SOS—a practical reference for future leadership roles.
  • Develop greater self-awareness as a leader.
  • Build a personal leadership philosophy.
  • Organize tools for future assignments.
  • Identify and maintain personal and professional relationships built at SOS.
  • Create a lasting resource for your career.

Saving your work (important)

  • Use one Canvas tab only for this assignment.
  • Do not switch browsers mid-work (progress is stored in Canvas, not this device).
  • Click Save regularly while you work.
  • When you leave, use Save & Exit (downloads a sealed backup .json file).
  • If progress resets, use Restore Backup with your own .json file (it will not work for another student’s file).

How you’ll be assessed

Completeness only — Complete or Incomplete based on whether required portfolio components are present.
Category Complete Incomplete
Completeness All required components are present: leadership philosophy, four weekly reflections (including Project X on Reflection 3), and at least two personal-choice resources, each marked complete. Instructor and peer feedback are optional and not required for Completeness. Missing one or more required components, or reflections are limited and mostly descriptive.

How this works

  • Completion is checklist-based: philosophy, four reflections, and at least 2 of 3 personal-choice resources — each finished with Mark complete. Instructor and peer feedback are optional and do not block completion. Rubric is Completeness only — Complete or Incomplete.
  • Progress is saved to Canvas (SCORM). Use Save / Save & Exit — do not rely on this browser alone.
  • Type your work here. Progress is stored in Canvas when you Save.

Required items

For papers and reflections, type or paste into the entry box (progress saves to Canvas), then mark complete to finish the section. Personal-choice items use the resource list (at least two required) — select a resource, then mark complete. Instructor and peer feedback are optional — not required to complete this activity. Add notes if useful and mark complete only if you choose to record them.

Export

Export a zip package of the contents you have filled out in this activity. The zip has two folders (Organized & Canvas Submission). Submit the Canvas Submission .txt file to the Canvas assignment labeled SOS Leadership Portfolio Assessment.
